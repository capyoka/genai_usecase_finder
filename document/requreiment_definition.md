# 生成AI事例検索サイト 要件定義（業務要件＋機能要件＋デザイン仕様｜FAISS＋ベクトル検索／最小管理UI）
## 1. 業務背景

- クライアント：**ITコンサルティングファーム／AI関連部署 部長**  
- 提供価値：国内の生成AI活用事例を**素早く発見**し、**短時間で要点把握**できる「提案前リサーチ用」サイト
- 現状課題
  - 類似事例の**横断検索に時間**がかかる  
  - リリース文／記事の**要点抽出に時間**がかかる  
  - 情報が個別管理（Excel／ブックマーク等）で**横展開が弱い**

---

## 2. 業務要件（Business Requirements）

- BR-01：**国内の生成AI事例を探索可能**であること（自然文・絞り込みの両方）
- BR-02：**短時間（5–15分）で要点把握**できること（タイトル／概要／リンクが即見える）
- BR-03：**業界・テーマ・組織名での絞り込み**が直感的にできること
- BR-04：**引用リンク**を提案資料へ転記しやすい形で提示すること
- BR-05：**CSVでの事例追加**がノンエンジニアでも可能（最小のアップロード操作のみ）

---

## 3. スコープ

- **検索方式**：OpenAI Embeddings → **FAISS（IndexFlatIP）** のみ  
  （BM25／ハイブリッド／LLMリランクは実施しない）
- **UIページ**：
  1) **/cases**：テーブル＋ファセットの従来型検索  
  2) **/chat**：RAG最小のチャット検索（根拠リンク併記）  
  3) **/admin/import**：CSVアップロード→即反映（最小管理画面）

---

## 4. 主要ユースケース

- UC-01（提案前準備）：営業が `/cases` で「カテゴリ=公共・自治体」「テーマ=業務プロセス改善」を選択し、  
  検索「窓口 生成AI」で上位10件を確認 → 3件のリンクを開いて要点をメモ
- UC-02（要件定義初期）：コンサルが `/chat` で「製造×議事録要約の国内事例は？」と質問 →  
  短文回答＋**[1][2]** の引用リンクをコピーして社内共有
- UC-03（データ更新）：担当者が `/admin/import` にCSVをドラッグ＆ドロップ → 先頭100行を目視確認 → 取込開始 → 即反映

---

## 5. データ仕様

### 5.1 入力CSV（固定カラム）
```
カテゴリ, 組織名, タイトル, 概要, テーマ, リンク, 担当者
```
- **担当者**：読み込み可だが**検索・表示には不使用**

### 5.2 正規化（軽量）
- テーマ：`,` `/` `・` `｜` を区切りとして**配列化**
- URL：`http/https` 付与、前後空白除去
- 必須チェック：`タイトル`・`概要`・`リンク` のいずれか欠落行を**スキップ**

### 5.3 内部保持（最小）
- **メタ表**（例：SQLite/Parquet）
  - `id (uuid)`, `category (text)`, `org (text)`, `title (text)`, `summary (text)`, `themes (text[])`, `link (text)`
- **ベクトル**
  - 埋め込み対象：`title + "
" + summary`
  - モデル：OpenAI `text-embedding-3-large`（必要に応じて `-small`）
- **FAISS**
  - `IndexFlatIP`（ID付き）

---

## 6. 画面要件（ページ別）

### 6.1 `/cases`（従来型検索）
- 検索バー（1行、自然文／キーワード）
- ファセット
  - カテゴリ（複数選択）
  - テーマ（複数選択）
  - 組織名（入力補助）
- 結果テーブル（関連度降順・**20件/ページ**）
  - 列：**タイトル（外部リンクアイコン付）／組織名／カテゴリ／テーマ（カンマ連結）／概要（3行省略）**
- 動作フロー
  1) ファセットで候補集合をメタ表から抽出  
  2) クエリを埋め込み → 候補集合のベクトルに対し FAISS 検索  
  3) TopK（例：50）→ページング表示

### 6.2 `/chat`（チャット検索）
- 入力：自然文の質問のみ
- 処理：質問を埋め込み → FAISS TopK（例：5–8） → 短文回答（OpenAI Chat）
- 表示：回答本文＋**引用**（`[1][2]…` 形式で**タイトル＆URL**を列挙）

### 6.3 `/admin/import`（CSV取込・最小）
- UI：CSV選択（D&D可）／**先頭100行プレビュー**／「**取り込み開始**」ボタン
- 結果：`{ total_rows, imported, skipped }` を画面表示
- 挙動：アップロード直後に**取込→埋め込み→FAISS追記**を実行し、即反映。

---

## 7. 検索仕様（共通）

- 埋め込み：OpenAI `text-embedding-3-large`
- 類似度：内積（cosine換算でも可）
- TopK：`/cases`=50、`/chat`=5–8（目安）
- 順位：FAISSスコア降順のみ（追加ブーストなし）

---

## 8. API仕様（最小）

### 8.1 従来型検索
`GET /api/v1/cases`  
**Query**：`q`, `category[]`, `theme[]`, `org[]`, `page`, `size`  
**Response**
```json
{
  "total": 123,
  "items": [
    {
      "id": "uuid",
      "title": "タイトル",
      "summary": "概要…",
      "org": "組織名",
      "category": "カテゴリ",
      "themes": ["テーマ1","テーマ2"],
      "link": "https://example.com",
      "score": 0.87
    }
  ]
}
```

### 8.2 チャット検索
`POST /api/v1/chat`  
**Body**
```json
{
  "messages": [{"role": "user", "content": "質問文"}],
  "filters": {"category": ["公共・自治体"], "theme": ["業務プロセス改善"], "org": ["長岡市"]},
  "top_k": 6
}
```
**Response**
```json
{
  "answer": "短い回答文…",
  "citations": [
    {"id": "uuid", "title": "タイトル", "link": "https://example.com"}
  ]
}
```

### 8.3 CSV取込
`POST /api/v1/admin/import`（multipart: `file`）  
**Response**
```json
{ "total_rows": 1000, "imported": 980, "skipped": 20 }
```
